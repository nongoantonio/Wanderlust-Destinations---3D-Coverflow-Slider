# 🌍 Wanderlust Destinations - 3D Coverflow Slider

Um projeto web moderno e altamente interativo desenvolvido com **HTML5**, **CSS3 (Glassmorphism & Flexbox)**, **JavaScript** e **Swiper.js**. O layout apresenta um carrossel 3D imersivo para exploração de destinos turísticos globais, completo com modais dinâmicos e design responsivo.

---

## ✨ Funcionalidades

- **Carrossel 3D Interativo:** Utiliza o efeito *Coverflow* do Swiper.js com navegação suave por mouse, teclado ou touch.
- **Modais Dinâmicos:** Clique em "Explorar Destino" para abrir uma janela modal com detalhes e preços.
- **Design Moderno & Glassmorphism:** Cores futuristas, efeitos de desfoque e cartões estilizados.
- **Totalmente Responsivo:** Compatível com dispositivos móveis, tablets e desktops.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**
- **CSS3** (Variáveis, Flexbox, Animações e Glassmorphism)
- **JavaScript (ES6+)**
- **Swiper.js** (Biblioteca de Carrossel 3D)
- **Google Fonts** (Poppins)
