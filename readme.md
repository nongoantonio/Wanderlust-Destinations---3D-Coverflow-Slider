# 🌍 Wanderlust Destinations - 3D Coverflow Experience

> Um projeto web moderno, elegante e altamente imersivo desenvolvido para explorar destinos turísticos de alto padrão através de uma interface inspirada em design de agências de viagens de luxo.

---

## ✨ Sobre o Projeto

Este projeto foi desenvolvido com foco total em experiência do usuário (**UX/UI**), utilizando um carrossel 3D interativo (*Coverflow*) com suporte a navegação por setas dedicadas, gestos de toque, rolagem do mouse e teclado. O design adota conceitos modernos de **Glassmorphism**, gradientes dinâmicos e cartões altamente responsivos.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** (Estrutura semântica avançada)
- **CSS3** (Variáveis, Flexbox, Animações fluidas e Glassmorphism)
- **JavaScript (ES6+)** (Lógica de modais e integração de eventos)
- **Swiper.js** (Biblioteca de carrossel 3D de alta performance)
- **Google Fonts** (Plus Jakarta Sans)

---

## 🎯 Funcionalidades Principais

- **Carrossel 3D Interativo:** Navegação suave entre os cartões com profundidade visual e foco dinâmico no item ativo.
- **Setas de Navegação Personalizadas:** Botões laterais flutuantes com efeitos de transição para scroll rápido e preciso.
- **Modais de Detalhes:** Janela interativa que exibe informações aprofundadas e preços ao clicar em "Explorar".
- **Design Responsivo:** Adaptado perfeitamente para desktops, tablets e dispositivos móveis.
